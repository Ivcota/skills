# The ONE Thing — Extraordinary Results from a Single Priority

**Core principle.** *"Extraordinary results are directly determined by how narrow you can make your focus."* (Keller & Papasan, 2013, p. 10). Success is sequential, not simultaneous — line up the right dominoes, then topple the first one.

**Leverage test.** If doing X makes the other items on your list either easier or unnecessary, X is your ONE Thing. If it doesn't, keep searching (p. 94).

Citations in the form `(p. N)` point to the source PDF. Full sources: [sources.md](sources.md).

## Interaction

When invoked, run this workflow. Do not dump reference content — walk the user through it.

**Step 1 — Declare the mode.** Open with one sentence naming which mode you're in. Modes are forks; the user must see which one they're in (microinteractions principle: make current mode highly visible).

- **Big-Picture mode** — when the user is asking about life, career, company strategy, a quarter or year. Walks the full 7-level cascade.
- **Small-Focus mode** — when the user is asking about today, this week, the next block of hours. Skips to levels 5-7 of the cascade.

If unclear, ask once: *"Big-Picture (life/career/company) or Small-Focus (this week / right now)?"*

**Step 2 — Surface the Big & Specific goal.** Ask the user for a concrete goal at the level above where they're working. Reject "How can I grow sales?" — push for "What can I do to **double sales in six months**?" (p. 109). Without a Big & Specific input, the Focusing Question yields a Small & Broad answer.

**Step 3 — Walk the cascade.** Run Goal Setting to the Now from the appropriate starting level down to "Right Now". One Focusing Question per level. Write each answer down — written goals are 39.5% more likely to be accomplished (Matthews, p. 132).

**Step 4 — Output the artifact.** End with a filled-in Focusing Question and a time block. Format:

```
ONE Thing (right now): <single specific action>
Time block:            <date, start–end, location>
Bunker:                <what's off / who's been told>
Defense:               <which Three-Foot-Rule no's you're prepared to say>
```

If the user has a notes vault or calendar tool available, offer to save it there. Otherwise return it inline.

**Step 5 — Re-ask cadence.** Tell the user when to re-run this skill: weekly for Daily/Right Now, monthly for the full cascade, quarterly for the Big & Specific question (p. 184). The ONE Thing changes as conditions change.

## The Focusing Question — the signature moment

> **"What's the ONE Thing I can do such that by doing it everything else will be easier or unnecessary?"** (pp. 9, 93)

**Anatomy** (pp. 93-94):
- *"What's the ONE Thing"* — forces a single answer; no hedging.
- *"I can do"* — embedded command. Not "should," "could," or "would" (those are intentions).
- *"such that by doing it"* — adds a causal criterion.
- *"everything else will be easier or unnecessary"* — the leverage test. This identifies the first domino.

Use the question verbatim. Substituting "should / could / would" turns a commitment into an intention (p. 93).

## Goal Setting to the Now — the cascade

Pull a distant purpose into a single present action via a 7-level nested cascade — *"like a Russian matryoshka doll"* (p. 127). Each level answers one Focusing Question.

```
1. Someday Goal     → What's the ONE Thing I want to do someday?
2. Five-Year Goal   → Based on my Someday Goal, what's the ONE Thing I can do in the next five years?
3. One-Year Goal    → Based on my Five-Year Goal, what's the ONE Thing I can do this year?
4. Monthly Goal     → Based on my One-Year Goal, what's the ONE Thing I can do this month?
5. Weekly Goal      → Based on my Monthly Goal, what's the ONE Thing I can do this week?
6. Daily Goal       → Based on my Weekly Goal, what's the ONE Thing I can do today?
7. Right Now        → Based on my Daily Goal, what's the ONE Thing I can do right now?
```
(Fig. 24, p. 128)

Don't skip steps. *"What's the ONE Thing I can do right now so I'm on track to achieve my someday goal?"* — *"Doesn't work. The moment is too far from the future for you to clearly see your key priority"* (p. 130).

→ Deep dive: [references/goal-setting-to-the-now.md](references/goal-setting-to-the-now.md)

## Time Blocking — protect the ONE Thing

*"If disproportionate results come from one activity, then you must give that one activity disproportionate time"* (p. 137).

**Block order** (p. 139):
1. Time off (first — *"Resting is as important as working"* p. 140).
2. ONE Thing (second — most important appointment is with yourself).
3. Planning time (third — one hour/week to review goals, p. 143).

**How much.** *"My recommendation is to block four hours a day. This isn't a typo... that's the minimum"* (p. 141).

**When.** As early as possible — willpower is highest in the morning (p. 63). Sample: 8 A.M.–Noon (Fig. 29, p. 139).

**Defense — four tactics** (pp. 147-148):
1. **Build a bunker** — a place out of disruption.
2. **Store provisions** — snacks, drinks, supplies; no trips out.
3. **Sweep for mines** — phone off, email closed, browser quit.
4. **Enlist support** — tell people what you're doing and when you're available.

If the block gets bumped: *"if you erase, you must replace"* (p. 147). Don't break the chain (Seinfeld red-X, p. 144).

## Common mistakes

| Mistake | Fix |
|---|---|
| "Should / could / would do" instead of "can do" | Keep the question verbatim. Action beats intention (p. 93). |
| Small & Broad questions ("How can I grow sales?") | Go **Big & Specific**, then convert (p. 109). |
| To-do list as priority list | Apply Pareto, then Extreme Pareto, until one item remains (p. 32). |
| ONE Thing scheduled late in the day | Block 4 hours as early as possible (p. 141). |
| Phone + email + Slack open during the block | Sweep for mines (p. 147). |
| Multiple new habits at once | One habit, ~66 days, then stack (p. 48). |
| "Balanced life" as goal | **Counterbalance**: long at work, short in personal life. Family/health/integrity are glass balls (p. 72). |
| Skipping cascade steps | Walk all seven levels (p. 130). |
| Writing goals but not reviewing | Send weekly progress to a coach — 76.7% success rate (Matthews, p. 163). |

## Quick diagnostic

| Symptom | First move |
|---|---|
| "I have too many priorities" | Run **Goal Setting to the Now** (p. 128) |
| "I worked all day and got nothing done" | 4-hour morning block; sweep for mines (pp. 141, 147) |
| "I can't say no" | Adopt the **Three-Foot Rule** (p. 170) |
| "I'm burning out chasing balance" | Switch to **counterbalance** (pp. 70-72) |
| "I have a goal but don't know what to do today" | Walk the full cascade (p. 130) |
| "My ONE Thing keeps slipping" | Move the block to first thing in the morning (p. 63) |
| "I plateaued" | Move from **E** to **P** (p. 155) |
| "I know what to do but can't make myself" | Find a coach (Ericsson, pp. 163-164) |
| "My environment keeps pulling me back" | Trial-walk the path; curate People + Place (p. 181) |
| "Big goal feels impossible" | Ask a **Possibility** question (pp. 110-112) |

## Ethical boundaries

- *"One thing"* is not *"only one thing forever"* — it is at any moment in time (p. 184). Re-ask as conditions change.
- Counterbalance has a one-way exception: family, health, friends, integrity are **glass balls**; work is rubber (Patterson, pp. 71-72).
- Mary Keller's move — *"Gary, that's not my ONE Thing right now"* — is a legitimate answer (p. 199). The Focusing Question is a two-way filter.
- Saying no has etiquette (Seth Godin, p. 169): with respect, promptly, with a lead to someone who might say yes.
