# Essence

Essence is the mindset layer of Essentialism. McKeown's road map says the first part of the book establishes three realities: choice, noise, and trade-offs. Source: `../sources.md`, `index_split_007.txt`.

## Use Essence When

- The user feels obligated by every request.
- Everything in a list feels equally important.
- The user wants a priority list but has not accepted trade-offs.
- A team says it has many priorities.
- A decision is being made by default, precedent, guilt, or pressure.

## Core Moves

### 1. Reclaim Choice

Convert obligation language into choice language.

| Default | Essentialist Reframe |
|---|---|
| "I have to attend." | "I choose to attend because..." |
| "They need this from me." | "I choose whether this is my highest contribution." |
| "I cannot say no." | "I can choose the consequence I am willing to carry." |

Source anchor: Chapter 2 contrasts learned helplessness with choosing. `index_split_011.txt`-`index_split_013.txt`.

### 2. Separate Noise From Signal

Assume most options are not equally valuable. The diagnostic question is not "Is this useful?" but "Is this one of the vital few?"

Use:

1. List current commitments.
2. Mark the few that create disproportionate contribution.
3. Mark everything else as candidate noise.
4. Do not protect "good" work from scrutiny.

Source anchor: Chapter 3 uses the vital-few/trivial-many distinction. `index_split_014.txt`.

### 3. Force The Trade-Off

Every real yes spends time, attention, credibility, or energy. Before saying yes, ask what the yes will make impossible.

Prompts:

- "What will this crowd out?"
- "Which problem do I want?"
- "What would I stop doing if this became the priority?"
- "What trade-off am I pretending does not exist?"

Source anchor: Chapter 4 says trade-offs are unavoidable. `index_split_015.txt`.

## Diagnostic

Ask:

1. "What is the single highest contribution this person/team/project can make?"
2. "What are we currently treating as a priority that is not actually first?"
3. "What good thing is blocking the great thing?"
4. "What would happen if we stopped trying to make everything work?"
5. "Which problem do we choose?"

## Common Failure Modes

| Failure | Symptom | Correction |
|---|---|---|
| Approval filter | Yes is the default. | Pause before agreeing; answer from contribution. |
| Equal importance | Everything is urgent. | Rank by disproportionate value. |
| Hidden trade-off | People are surprised later. | Name the cost before committing. |
| Priority inflation | Many "first" things. | Decide the one first thing. |
| Passive choice | Calendar reflects other agendas. | Rebuild from chosen contribution. |
