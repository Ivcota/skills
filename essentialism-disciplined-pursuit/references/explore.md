# Explore

Explore is the first process step after the Essentialist mindset. McKeown argues that Essentialists explore more before committing because they intend to commit to fewer things later. Source: `index_split_007.txt`, `index_split_017.txt`.

## Use Explore When

- The user is rushing to choose.
- A problem definition feels shallow.
- The user needs criteria for opportunities, hires, projects, or meetings.
- A team is constantly reacting.
- The user has no protected thinking time.

## Practices

### Escape

Create deliberate space for thought. The book uses examples such as Do-Not-Call-Monday, Bill Gates's Think Week, and blank calendar blocks. Sources: `index_split_018.txt`, `index_split_020.txt`, `index_split_021.txt`.

Application:

1. Block uninterrupted time.
2. Remove calls, messages, and inbox scanning.
3. Enter with one question.
4. Leave with a decision, sharper question, or evidence gap.

### Look

Look for the lead: the real story beneath the data. The Nora Ephron example teaches that raw facts are not necessarily the point. Sources: `index_split_022.txt`, `index_split_025.txt`.

Application:

- Ask, "What is this really about?"
- Review notes for patterns, not exhaustive details.
- Go to the field before designing a solution.

### Play

Play expands the range of options and can improve exploration. Use it when the user is treating creativity as wasted time. Source: `index_split_029.txt`.

### Sleep

Protect the asset. The work depends on the person making judgments, so sleep belongs in decision quality, not outside it. Sources: `index_split_032.txt`, `index_split_033.txt`.

### Select

Apply extreme criteria. The 90 Percent Rule is the explicit scoring model:

1. Pick the most important criterion.
2. Score the option 0-100.
3. Reject anything under 90.

Sources: `index_split_035.txt`, `index_split_036.txt`, `index_split_037.txt`.

## Opportunity Filter

| Question | Keep Only If |
|---|---|
| What am I deeply inspired by? | The option connects to real motivation. |
| What am I particularly talented at? | The option uses distinctive strengths. |
| What meets a significant need? | The option matters outside personal preference. |
| Is this a 90+? | The option clears extreme criteria. |
| Is it a clear yes? | The answer is not grudging or fuzzy. |

Source: Road Map and Select chapter. `index_split_007.txt`, `index_split_036.txt`.

## Common Failure Modes

| Failure | Symptom | Correction |
|---|---|---|
| Reacting too early | First visible option becomes the plan. | Add exploration space. |
| Overvaluing activity | Busyness substitutes for discernment. | Block calendar time. |
| Solving before seeing | Product solves the wrong problem. | Observe the real context. |
| Weak criteria | Many good options survive. | Use 90 Percent scoring. |
| Sleep debt | Judgment gets worse while effort rises. | Protect the asset. |
