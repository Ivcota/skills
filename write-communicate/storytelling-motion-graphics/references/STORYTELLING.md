# Storytelling for motion graphics

- Write the story in one sentence first, then split into ~7 beats:
  1 Hook (0–4 s): something moves immediately; a question or event.
  2 Problem / setup: the stakes, the context number.
  3–4 Build: tension rises, counters climb, the shared element grows.
  5 Reveal: the turn — colour/mood/music shift.
  6 Consequence: make it personal (what it means for a viewer).
  7 Payoff: one end frame with the takeaway + a wry/memorable line; hold ≥ 3 s.
- One shared element travels through all scenes so it reads as one story, not slides.
- Camera: dive into the detail that matters next; scale 1.0→1.15 pushes, dives through objects into the next scene.
- Numbers: animate with counters (ease-out), always with units; show deltas (%), colour = meaning (green up, red down, steady — never flashing).
- Icons: Lottie (useAnimations line icons, Noto animated emoji) as accents, not wallpaper.
- Music follows the arc: bright build, drop/minor turn at reveal, resolve on payoff. SFX: whoosh on transitions, tick on counters, hit on reveal.
