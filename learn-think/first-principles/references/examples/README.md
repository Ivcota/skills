# Worked-Example Contract

Every worked example must show the following for every step:

1. **Input**
2. **Work performed**
3. **Output**
4. **Gate result**
5. **What happens next**

Make the reasoning between steps visible. When new Evidence causes the approach to repeat, show which step it returns to and why.

The canonical worked example is [Choosing Dinner Before a Movie](./DINNER.md).
