# Million Dollar Weekend Checklist

Print this. Run it in order. Each phase has a go/no-go score at the bottom — below threshold means go back, don't advance. The other reference files unpack each phase in depth; this one is the operational worksheet that ties them together.

Source throughout: Noah Kagan with Tahl Raz, *Million Dollar Weekend* (Portfolio/Penguin, 2024).

---

## Pre-flight (this week)

From "Start Here" + Ch 1 + Ch 2. Build the muscle before the weekend starts.

- [ ] **Sign the contract** — write your name, sign, date ("Start Here" Challenge)
- [ ] **Calculate your Freedom Number** (Ch 1):
  - Housing: $______ /month
  - Food + travel: $______ /month
  - Savings + investment: $______ /month
  - **Freedom Number total: $______ /month**
- [ ] **Dollar Challenge** — text 1 person, send the script verbatim (Ch 1):
  > "Hey [first name] / I'm reading this book Million Dollar Weekend and they told me I need to get $1 from someone. / You're the first person I thought of, and it would mean a lot to have your support. / Can you send me $1 right now?"
- [ ] **Coffee Challenge** — today, in person, ask for 10% off, say nothing else (Ch 2)
- [ ] **Set Rejection Goal**: ______ rejections by end of this week (Kagan: 25+; his dad: 100) (Ch 2)

Deep dive: `see references/just-start.md` and `references/asking-muscle.md`.

**Go/no-go to advance:** all 5 boxes checked.

## Saturday — Run the One-Minute Business Model (Ch 4)

You need a million-dollar opportunity, not just a clever idea.

- [ ] **Google Trends** — is the market dying, flat, or growing? (want flat or growing): ____________
- [ ] **Million-dollar opportunity check**: market size × price ≥ $1M?
  - Size of market (ideal customers): ______________
  - Price point: $______
  - Total value (size × price): $______________
  - **≥ $1,000,000?** Y / N
- [ ] **Unit economics**:
  - Revenue per unit: $______
  - Cost per unit: $______
  - **Profit per unit (Revenue − Cost): $______**
  - **$1,000,000 ÷ profit per unit = ______ units to sell**
- [ ] If the math doesn't work, **pivot via a Revenue Dial** (pick one):
  - [ ] Average order value
  - [ ] Frequency (one-off → recurring)
  - [ ] Price point
  - [ ] Customer type
  - [ ] Product line
  - [ ] Add-on services
- [ ] Re-run the math after pivoting. Repeat until **$1M opportunity confirmed** or pick a new idea.

Deep dive: `see references/business-model.md`.

**Go/no-go to advance:** $1M opportunity confirmed OR pivot completed and re-verified.

## Sunday — 48-Hour Money Challenge (Ch 5)

The Golden Rule of Validation: **three real customers in 48 hours, cash collected — not promised.**

- [ ] **Build Dream Ten list** — 10 names with contact info from your Zone of Influence
  (sources: FB friends, FB groups, contact favorites, LinkedIn, former colleagues, past clients, text-message lists, church/synagogue, Twitter)

|---|------|---------|-------------|-----------|-----------|-------|

| 2 |      |         |             |           |           |       |
| 3 |      |         |             |           |           |       |
| 4 |      |         |             |           |           |       |
| 5 |      |         |             |           |           |       |
| 6 |      |         |             |           |           |       |
| 7 |      |         |             |           |           |       |
| 8 |      |         |             |           |           |       |
| 9 |      |         |             |           |           |       |
| 10|      |         |             |           |           |       |

- [ ] **Draft offer sentence** in Price + Benefit + Time format:
  > "For $____, I will ____________________________, in just ____________."
- [ ] **Reach out to all 10** — call/text/DM/email. Active, not passive. No mass blast.
- [ ] **Run Listen → Options → Transition** with each. Three Listen questions (use *what/how*, not *why* or yes/no):
  - "What's the most frustrating thing about what's currently going on?"
  - "How would having [X] make your life better?"
  - "What do you think that [X] should cost?"
- [ ] **Collect cash** from at least 3 — PayPal / Venmo / Stripe / Cash App. **Promises do not count.**
- [ ] When rejected, run the **4-question script**:
  - Why not?
  - Who is one person you know who would really like this?
  - What would make this a no-brainer for you?
  - What would you pay for that?
- [ ] **Tally:** ____ paying customers in 48 hours.

Deep dive: `see references/money-challenge.md`.

**Go/no-go to advance:** 3 paying customers ≥ $1 in 48 hours, **cash collected**. Zero = pick next idea and repeat the weekend.

  - Medium: ____________________
  - Large: ____________________
- [ ] **Set up landing page + lead magnet** (Ch 7):
  - Email tool: SendFox / Mailchimp / ConvertKit
  - Landing page: Webflow (or similar)
  - Lead magnet: ____________________
- [ ] **Write 3-email autoresponder** (Ch 7):

- [ ] **Set ONE goal** (number + deadline): $______ by ______ (date)

  contacting your network / paid ads / social ads / content marketing / cold outreach / target-market blogs / influencer marketing / PR / SEO / giveaways / collaborations
- [ ] **Build Experiment List spreadsheet**:

|--------|----------------|--------------|------|------|
|        |                |              |      |      |
|        |                |              |      |      |
|        |                |              |      |      |
|        |                |              |      |      |

- [ ] **Day 30**: double down on winners, kill losers (no loyalty to dead channels — they're opportunity cost)
- [ ] **Over-deliver to first 100 customers** — the unscalable acts:
  - Reply to every comment / email by hand
  - Give first customers your personal phone number if possible
  - Ask each one: **"What is one thing we can do today that will make you twice as happy?"**

Deep dive: `see references/growth-machine.md`.

**Go/no-go to advance:** at least 1 channel hit ≥ best-guess expected sales.

## Ongoing systems (Ch 9)

Optimize for happiness, not maximum revenue. 52 chances a year.

- [ ] **Write Dream Year** across four categories:
  - Work: ____________________
  - Health: ____________________
  - Personal: ____________________
  - Travel: ____________________
- [ ] **Set yearly goals** in each category
- [ ] **Color-code your calendar**:
  - Blue = Work
  - Green = Health
  - Purple = Personal
  - Yellow = Travel
- [ ] **Find ONE accountability buddy**
- [ ] **Sunday 15-min P-review email** — every Sunday, to the buddy. Cover:
  - How will I pick what to do this week?
  - Are tasks moving me toward my goal?
  - Do I need to schedule lazy time?
  - How do I double down on what's working?
- [ ] **Networking**: 5 prefluencer compliments per week (no ask) + 1 referral ask per meeting

Deep dive: `see references/52-chances.md`.

## Go/No-Go Scoring Rubric

At each phase, rate yourself honestly. Below threshold = go back, don't advance.

| Phase | Score required to advance |
|---|---|
| Pre-flight | All 5 boxes checked |
| Friday | 1 idea picked, passes painkiller filter |
| Saturday | $1M opportunity confirmed OR pivot done and re-verified |
| Sunday | 3 paying customers ≥ $1 in 48h (cash collected, not promised) |
| Growth 30 days | At least 1 channel hit ≥ best-guess expected sales |

Three paying customers is the only validation that counts. Promises are polite rejection. Cash makes it real.
