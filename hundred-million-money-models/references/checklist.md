## Phase 0 — Unit Economics Baseline (the CFA breakdown)

Before designing the model, capture today's numbers. You'll re-measure after each phase.

### The CFA equation

```
CFA Headroom  =  30-day Gross Profit per customer  −  (CAC + 30-day cost-to-serve)
CFA Multiple  =  CFA Headroom  ÷  (CAC + 30-day cost-to-serve)
```

**Pass bar (p. 181):**
- **Bare minimum:** CFA Headroom ≥ 0 (one customer pays for themselves)
- **Good:** CFA Headroom &gt; 0 with margin to reinvest
- **$100M Money Model:** CFA Multiple ≥ 1 (one customer's 30-day GP funds the *next* customer's full acquisition + delivery)

### How each offer type moves the equation

- **Attraction Offer** → lowers effective CAC by raising lead-to-customer conversion + built-in upsells
- **Upsell Offer** → raises (c) directly. McDonald's lift: $0.25 → $3.00 GP = 11.6× (p. 80)
- **Downsell Offer** → raises conversion rate, effectively lowering (d) per acquisition
- **Continuity Offer** → defers cash from this 30-day window but compounds the pool of customers future upsells run on (don't expect Continuity to fix CFA today)

## Phase 1 — Build the Attraction Offer

Goal: cover CAC + delivery cost, ideally multiple times over.

### 1.1 Pick the type

- [ ] **Win Your Money Back** — only if refund rate &lt; 5%
- [ ] **Giveaways** — only if you have a "grand" Grand Prize and have consulted counsel
- [ ] **Decoy Offer** — when you need cheap leads + know more than the customer about their problem
- [ ] **Buy X Get Y Free** — when you have multiple units or long-duration deliverables
- [ ] **Pay Less Now or Pay More Later** — when you can promise a clear yes/no result in &lt;1 month

### 1.2 Free vs Discount

- [ ] **Free** for max leads (low show-up cost industries)
- [ ] **Discount** for high no-show-cost industries (doctors, lawyers, dentists)

### 1.3 Recipe checklist (Win Your Money Back example)

- [ ] Goal is **easy to track** (existing tools where possible)
- [ ] Goal **realistically gets results**
- [ ] One qualifying action **advertises the business** (post, tag, refer, testimonial)
- [ ] Store-credit application is **spread over time**, not given up front
- [ ] Have an upsell ready before launch ("*the real money comes from people who succeed and you have something else to offer*")

### 1.4 Sanity-check guardrails

- [ ] Will refund this offer if asked, no questions
- [ ] Hard-selling not required
- [ ] Legally cleared
- [ ] Honest claims; no exaggerated values

## Phase 2 — Add the Upsell Offer

Goal: get 30-day profits *well above* CAC + delivery.

### 2.1 Map the next problem

- [ ] What problem does the Attraction Offer **solve**?
- [ ] What problem does that solution **create**?
- [ ] What's the **time gap** between the two?

### 2.2 Pick the type

- [ ] **Classic Upsell** — for the immediate next problem ("X without Y!")
- [ ] **Menu Upsell** — when you have multiple offers to choose from
- [ ] **Anchor Upsell** — when budgets vary widely (always have a 5–10× anchor)
- [ ] **Rollover Upsell** — for lapsed, upset, competitor's-upset, or current customers

### 2.3 Magnetic Middle pricing audit

- [ ] If most are buying small → narrow gap to medium, widen to large
- [ ] If most are buying medium → narrow gap to large
- [ ] If most are buying large → **raise all prices**

### 2.4 Mechanics

- [ ] **BAMFAM:** customer knows next meeting + reason before leaving
- [ ] **Faster access = higher value perception** (ideally before they say yes)
- [ ] **Bundles are named** (Whale, Total Transformation, Minimum)
- [ ] **Card On File** capture on first transaction

### 2.5 Pricing tweaks (optional)

- [ ] Add 5–50% for guarantee/insurance/warranty
- [ ] If lots of customers are buying large → raise all prices

## Phase 3 — Add the Downsell Offer

Goal: convert nos into yeses without dropping price for the same product.

### 3.1 The hard rule

- [ ] **Never sell the same thing for cheaper.** That's a discount, not a downsell.

### 3.2 Decision tree

- [ ] Customer says "*costs too much up front*" → **Payment Plan Downsell**
- [ ] Customer rejects entirely + service is recurring + customer must do work → **Trial With Penalty**
- [ ] Customer wants different scope OR one-time service → **Feature Downsell**

### 3.3 Payment Plan ladder (use in order)

1. [ ] Reward paying in full (prepay discount)
2. [ ] 3rd-party financing / credit card / layaway
3. [ ] Half now, half later
4. [ ] Scale check 1–10
5. [ ] ⅓ × 3
6. [ ] Evenly spread across term
7. [ ] Free Trial (escalate to Trial With Penalty)

### 3.4 Trial With Penalty checklist

- [ ] Use as **downsell**, not lead offer
- [ ] Always get a credit card
- [ ] Set expectation of staying & paying *before* trial starts
- [ ] Explain fees *after* getting card ("*just how we've always done it*")
- [ ] Sales meetings are part of trial criteria
- [ ] Customers initial fee clauses separately
- [ ] Externally call it "Free Trial," not "Trial With Penalty"

### 3.5 Feature Downsell sequence

1. [ ] Cut a high-value feature first, drop price *a little* — drives re-upsell
2. [ ] If no re-upsell, keep removing features and dropping price
3. [ ] Name combinations (Whale / Minimum)
4. [ ] After two downsells without yes, scale check 1–10
5. [ ] Close every tier with "*Deal?*" or "*Fair enough?*"

## Phase 4 — Add the Continuity Offer

Goal: stack recurring cash; get one last sale in the 30-day window.

### 4.1 Sequence rule

- [ ] Continuity is **last**, never first
- [ ] Standalone continuity offers in ads are forbidden until front-end is profitable

### 4.2 Pick the type

- [ ] **Continuity Bonus** — high-value bonus *if* they sign today
- [ ] **Continuity Discount** — free time *if* they commit
- [ ] **Waived Fee** — strong lock-in, slow-payoff services

### 4.3 Bonus pricing table (set standalone vs membership ratio)

| Target % choosing membership | Standalone × monthly continuity |
|------------------------------|--------------------------------|
| 50% | 1.33× |
| 60% | 1.66× |
| 70% | 2× |
| 80% | 2.33× |
| 90% | 2.66× |

### 4.4 Discount application choice

- [ ] **Up Front** — only if industry has reliable contract enforcement
- [ ] **At The End** — earned via on-time payments
- [ ] **Spread Over Time** — safest default
- [ ] **After 1–2 Payments** — bake in via "first and last month" or activation fee

### 4.5 Waived Fee specs

- [ ] Fee = 3–5× monthly rate
- [ ] Commitment ≥ 12 months
- [ ] Fee drops after commitment is fulfilled (equitable)
- [ ] Justify the fee at point of sale ("*it costs us money to get you started*")

### 4.6 Cancellation policy

- [ ] Documented cancellation policy exists
- [ ] Customers know how to cancel (visible inside the product)
- [ ] Cancellation fee = the discount they got (Hormozi's preferred)
- [ ] Exit interview offered to every cancellation
- [ ] If &gt;5% want to cancel early → **fix the product**, not the contract

### 4.7 Optional revenue lifts

- [ ] Switch to 4-week billing (not monthly): +8.3% annual revenue
- [ ] Add 3% processing fee, waivable with second form of payment
- [ ] Set bulk-prepay upsell at "buy 5 months get 1 free"

## Phase 5 — Assembly Rules (p. 176–178)

- [ ] **One stage at a time.** Perfect Phase 1 before adding Phase 2. "*It will break your business*" otherwise.
- [ ] **Measure in quarters, not weeks.**
- [ ] **Raise prices in stages.** Start cheap → harvest yeses + feedback → raise until revenue *drops*.
- [ ] **Simple Scales. Fancy Fails.** 100 ways to offer one product &gt; 100 products.
- [ ] **Use affiliate products** to fill gaps without delivery overhead.
- [ ] **Convert Attraction Offers into Continuity** with auto-renewal (e.g., "Buy 6 Months Get 6 Months Free" → month-to-month at month 12).
