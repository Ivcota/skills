# Application checklist

Editorial worksheet based on the cited framework references. Preserve iteration rather than treating this as a rigid author-prescribed sequence.

- [ ] Name one customer segment. Separate its profile from the offer. See [Canvas](canvas.md).
- [ ] Record jobs, pains, and gains, including priorities. Mark evidence and assumptions separately. See [Canvas](canvas.md).
- [ ] List products and services. Explain their relievers and creators. Draw specific matches and retain gaps. See [Canvas](canvas.md).
- [ ] Explore alternatives using customer insights or available assets. See [Design](design.md).
- [ ] Compare alternatives on customer-relevant dimensions. See [Design](design.md).
- [ ] Identify whether the uncertainty concerns needs, solution preferences, or payment. Propose a test. See [Test](test.md).
- [ ] State which kind of fit the evidence supports and what remains unproven. See [Canvas](canvas.md).
- [ ] Revisit changed assumptions and the surrounding business model. See [Evolve](evolve.md).

## Working output

Use this editorial structure when applying the skill:

1. Segment and context.
2. Customer profile, with evidence pointers and assumptions.
3. Value map and explicit matches.
4. Alternatives and selection rationale.
5. Current fit evidence and next investigation.

Source support is in the linked sections. No source-derived numerical score or universal acceptance threshold is available.
