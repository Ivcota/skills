# Solution Architecture Checklist

Use this worksheet when the skill fires.

## 1. Business Context

- [ ] Business problem is stated.
- [ ] Business capabilities are listed.
- [ ] Stakeholders are listed.
- [ ] Scope and out-of-scope items are explicit.
- [ ] Assumptions are explicit.
- [ ] Constraints are explicit.
- [ ] Dependencies are explicit.
- [ ] Risks and mitigations are explicit.

## 2. NFRs

- [ ] Scalability target
- [ ] Availability/reliability target
- [ ] Performance target
- [ ] Security/compliance target
- [ ] Maintainability target
- [ ] Portability/interoperability target
- [ ] Capacity target

## 3. Architecture Views

- [ ] Business view
- [ ] Logical view
- [ ] Process view
- [ ] Deployment view
- [ ] Implementation view
- [ ] Data view
- [ ] Integration view
- [ ] Infrastructure view
- [ ] Security view
- [ ] Operational view

## 4. Quality Pillars

- [ ] Performance bottlenecks identified.
- [ ] Security layers defined.
- [ ] Blast radius is limited.
- [ ] Failure modes are listed.
- [ ] RTO/RPO are defined.
- [ ] Recovery is tested.
- [ ] Operations are automated where practical.
- [ ] Runbook exists and is current.
- [ ] TCO is calculated.
- [ ] Budget and forecast are reviewed.

## 5. Decisions

- [ ] Major decisions list options considered.
- [ ] Pros and cons are captured.
- [ ] Rationale is tied to business goals and NFRs.
- [ ] Trade-offs are explicit.
- [ ] Validation plan is defined.

## 6. Review Output

End with:

```markdown
Architecture verdict: [ready / needs work / blocked]
Top risks:
1. [risk]
2. [risk]
3. [risk]
Required changes:
1. [change]
2. [change]
3. [change]
Open questions:
1. [question]
2. [question]
```
