# 12-Month KPI Checklist & Scorecard

A 12-month worksheet based on the "Making It Happen" sequence in *Key Person of Influence* (Harrington & Priestley, 2015). Work through it quarter by quarter. The five P's must be done in the prescribed order — Pitch, Publish, Product, Profile, Partnership — to a high standard. Almost-having a book means you have zero books on Amazon.

> *"There's no point trying to skip over any of the five steps… Almost having a book means you have zero books on Amazon."* — Ch 2

---

## Quarter 1: Pitch + start Publish

- [ ] Industry chosen (the one I love — not the one I drifted into)
- [ ] Micro-niche staked: ________________
- [ ] Big Game defined (six components):
  - Fun: ____
  - Rules: ____
  - Players: ____
  - Prize: ____
  - Way to win: ____
  - Way to lose: ____
- [ ] Social pitch (under 2 min) written + tested on real audience
- [ ] Audience response: emotionally-charged (love or hate), not polite
- [ ] 7-step presentation pitch written (Position → Articulate → Extrapolate → Solve → Prove → Ask → Uplift)
- [ ] Pitch rehearsed to the point I can do 3 min OR 3 hr from the heart, not from memory
- [ ] Three core payoffs articulated (more money / more recognition / more right opportunities)
- [ ] Book type chosen from the five (Thought leadership / Interviews / Tips / Picture / Creative)
- [ ] Book outline complete (1-2 hrs planned per chapter)
- [ ] One significant reader question the book answers: ________________

## Quarter 2: finish Publish + start Product

- [ ] First draft of book complete (30k-50k words) OR 10 articles drafted (1,000-1,500 words each)
- [ ] Book title tested on 5+ real people — picks the brand-enhancing winner that names the micro-niche
- [ ] Book live on Amazon by end of Q2
- [ ] One free idea-spreader live (podcast / info-kit / webinar)
- [ ] One high-value implementation product designed (productized service / digital product / physical product)
- [ ] Product run through Kevin's 10-question intangible-qualities checklist:
  - [ ] Unique in the marketplace?
  - [ ] Big-enough market that wants it?
  - [ ] Solves a real problem?
  - [ ] Powerful offer + competitive price?
  - [ ] Easy to explain how it works?
  - [ ] Magical transformation or demo?
  - [ ] Multifunctional?
  - [ ] Credible (real-customer) testimonials?
  - [ ] Independently proven results?
  - [ ] Answers the questions the buyer is thinking?
- [ ] Implementation, not information — premium tier sells "done for you", not "here's how"
- [ ] Built-to-scale-from-day-one path identified (digital / licensing / local partners / travel)

## Quarter 3: Profile

- [ ] YouTube channel live, first 5 videos shipped
- [ ] Slideshare deck(s) uploaded (or modern equivalent visual-deck channel)
- [ ] Facebook business page (or modern equivalent — same channel type, today's platform)
- [ ] LinkedIn profile fully populated, optimised for the micro-niche
- [ ] WordPress blog live with 5+ posts (or modern equivalent long-form blog)
- [ ] Twitter / micro-blog active (or modern equivalent short-form social)
- [ ] Niche-specialist handle adopted ("The [Niche] Doctor / Guy / Coach")
- [ ] Google search of my name returns page-one results across video + blog + slides + social + third-party press
- [ ] Content is occupying the buyer's ~7-hour deliberation window (podcast / video / blog / social touchpoints)
- [ ] Content is on-message and brand-safe — no "louder bad singer" amplification

## Quarter 4: Partnership + momentum

- [ ] List of 20+ potential partners ranked by leverage (lists / distribution / brand / capital / products)
- [ ] Three calls made on every partnership idea (no idea dies un-called)
- [ ] First partnership meeting executed using the six rituals:
  - [ ] Set the scene (neutral nice venue)
  - [ ] Bring a thoughtful (not expensive) gift
  - [ ] Make friends first
  - [ ] Do business last (20-30 minutes)
  - [ ] Pick up the bill (especially if I instigated)
  - [ ] Follow through within 15 minutes on every off-hand promise
- [ ] First deal closed in one of the five types (affiliate / co-promotion / product-creation / packaging / free-bundle)
- [ ] Win/win/win framing used (I win, you win, the customer wins)
- [ ] Language audit: I use opportunities, not requests, in every ask
- [ ] Networking goal is partnerships, not clients (verified by the 5 partnership-scouting questions)
- [ ] Public deadline + accountability mechanism live (Ready, Fire… Aim)

## Scoring Rubric (rate each 1–10)

Goal: 10/10 on every P. **A 10/10 means people want to phone their most prized contacts to introduce you, and openly share their time, contacts, and resources with you.** (Ch 3, line 932)

Most people rate themselves 7-8/10; a realistic starting score is 1-2/10. Be honest.

| P | Score (1-10) | Anchor question |
|---|--------------|-----------------|
| Pitch | __ | Can I answer "What do you do?" in <2 min with a response strong enough that the listener wants to refer me? |
| Publish | __ | Am I the author of a book on Amazon that is Googleable for my micro-niche? |
| Product | __ | Do I have ≥1 free idea-spreader AND ≥1 high-value implementation product (not just my hourly time)? |
| Profile | __ | Does page-one of Google for my name return video / blog / slides / social / third-party press? |
| Partnership | __ | Do I have active partnerships where both sides build a bigger bakery rather than fight over the pie? |
| **Total** | **__/50** | |

## Anti-pattern audit

Tick any that apply (each one is a failure mode from the book — fix before re-scoring above):

- [ ] I am a generalist — failure: *"You can't be a Key Person of Influence at 'all sorts of things.'"*
- [ ] My pitch gets polite "sounds interesting" responses (worse than a strong "I hate it")
- [ ] I'm waiting until I'm "ready" to write the book (it has no power until it's finished)
- [ ] My book title is cryptic — listeners can't tell what I'm a KPI in
- [ ] I'm focusing on selling books instead of using the book as a credibility tool
- [ ] I'm trading my time for money — I am my own only product
- [ ] I'm selling information, not implementation
- [ ] My product is one-size-fits-all / too general
- [ ] I'm invisible on Google for my name + niche
- [ ] I'm amplifying off-message content (a louder bad singer)
- [ ] I'm networking for clients, not partnerships
- [ ] I'm using the language of requests, not opportunities
- [ ] I'm trying to do this alone (no mentors, coaches, or peer group)
- [ ] I'm waiting for the "ideal time" — it never comes
- [ ] I'm on the merry-go-round of distraction (jumping to a new industry instead of finishing the five steps in this one)

---

## How to use this checklist

1. **Start of each quarter:** read the quarter's list end-to-end, commit to which items get done.
2. **Weekly:** tick boxes as they're truly complete (no "almosts").
3. **End of each quarter:** rate yourself on the five-P rubric, then run the anti-pattern audit. Anything ticked there outranks anything in next quarter's plan — fix it first.
4. **End of year 1:** target ≥7/10 on every P, with at least one P at 9-10. If you're below 5 on any P, repeat that quarter's work before moving on. You get no points for almost.
