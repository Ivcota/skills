# Templates — UnderdogSales Cold Outreach

Source: user-provided UnderdogSales framework notes, 2026-06-19.

## Opener lines

Use one of these shapes, adapted to the user's ICP, offer, and channel. Prefer no-oriented wording where “no” is the safe forward answer: no means consent or permission, not rejection.

1. “{Name}, we don't know each other. I'm calling as you're {title} of {company}, and I'd like to work with you. Can you help me understand if this is a good fit?”
2. “If I told you this visit/call was about {product/service/concept}, would a piece of you die inside?”
3. “Hey {name}, we don't know each other. If I told you this was a call about {problem}, you'd probably tell me {opposite}.”
4. “Would you be mad if I asked you something about {problem/context}?”

## Problem pitch

“When speaking with other {title/ICP}, they mention facing problems like:

1. {pain 1}, which causes {consequence 1};
2. {pain 2}, which causes {consequence 2};
3. {pain 3}, which causes {consequence 3}.

But perhaps you don't have any of these issues and you're in {ridiculously positive opposite}.”

## Problem ownership drill

- Problem pick: “Which of those, if any, is closest to what you're seeing?”
- Example: “What does that look like?”
- Impact: “What is the impact of that?”
- Root cause: “Where does it come from?”
- Summary: “Let me see if I got this right: {summary}. Is that fair?”

## Qualifying questions

Use these when the prospect asks a question or gives vague language.

- Clarify: “I'm confused. When you say {x}, what does that mean?”
- Options: “When you say {x}, do you mean A, B, or C?”
- The Why: “I'm guessing {x} is important to you for a reason?”

## No-oriented and disqualifying questions

Use these to test fit without chasing. A no-oriented question makes “no” feel safe and can move the conversation forward: “No, I wouldn't be mad,” “No, it wouldn't be a bad idea,” or “No, there isn't a reason not to.”

- Safety of no: “Would you be mad if I asked you something?”
- Negative frame: “You probably couldn't do {thing that would qualify them}?”
- Reduce problem: “You seem to be doing very well anyway.”
- Disqualify: “Even if we could fix that, it wouldn't be a priority, right?”

## Objection handling

Pattern:

1. Acknowledge.
2. Ask permission to ask a question.
3. Challenge the objection and redirect to the problem.

Template:

“Totally fair. Do you mind if I ask a quick question? Earlier you mentioned {owned problem/example}. If that keeps happening, what does it do to {impact area}?”

## OLQ / one last question

Permission:

- “You okay if I ask one last question before I go?”
- “Can I ask one last question before I go then?”

Question options:

1. “If you could improve one thing, what would it be?”
2. “What would have to change to consider this?”
3. “Have you closed your mind to the idea that it could be done better?”
4. Tailor the question to the live objection.

## Close

Use only after the prospect gives at least one concrete example and shows problem energy.

Process:

1. Summary: “Let me see if I got this right: {problem + example + impact}. Is that fair?”
2. Final challenge: “Do you mind if I ask a tough question? Have you accepted this is the way things are?”
3. Ask: “Would it be a bad idea to have a sit down and see if I can help you?”
4. Alternative ask: “Is there any reason to not put some time aside to explore this further?”

## Post-close

- One more objection: “You sure you're not going to wake up that morning and be like, ‘dang, I don't have this issue’?”
- Return to problem if needed: “The reason I ask is because you mentioned {problem/example/impact}.”
- Confirm invite.
- Send agenda in a separate invite.
- Arrange confirmation: “I'm going to give you a call/text before to confirm with you before the meeting.”
