# Scripts and Language Patterns

A Straight Line script is strategic preparation: the best truthful words in the best order, designed so the seller can focus on delivery, rapport, and buyer reactions.

## First Four Seconds

In the opening moments, the seller must be perceived as:

1. **Sharp as a tack** — quick, prepared, worth listening to.
2. **Enthusiastic as hell** — positive conviction without hype.
3. **Expert in the field** — credible guide.

These combine into: "this person is worth listening to."

### Opening ingredients

- Familiar address: use the buyer's first name when appropriate.
- Upbeat delivery.
- Seller and company identified early.
- Reason for contact / justifier.
- Permission to continue.

### Opener pattern

```text
Hi, is [Name] there?
[Name], it's [Seller] with [Company]. How are you?
The reason I'm reaching out is [specific justifier].
If you have [short time], I'd like to ask a couple quick questions so I can see if this is relevant. Fair enough?
```

## Script architecture rules

1. **Do not front-load.** Frame; save strong material for loops.
2. **Benefits before features.** Mention features only as context for buyer-relevant benefits.
3. **Use stopping-off points.** Check-ins: "Make sense?" "Are you with me?" "You follow?"
4. **Write spoken language.** Natural, concise, expert.
5. **Make it flow.** Read aloud and revise rhythm/transitions.
6. **Truth well told.** No lies, misleading omissions, or unsupported exaggerations.
7. **Energy in / benefits out.** Balance every ask with value and ease.
8. **Use a series of scripts.** Opening, questions, presentation, rebuttals, loops.

## Presentation body pattern

1. Transition from intelligence gathering: "Based on what you told me..."
2. Name the product/process/program/service.
3. Give one benefit tied directly to the buyer's need.
4. Add proof, comparison, metaphor, or credible support if true.
5. Check in: "Make sense?"
6. Repeat benefit/check-in up to two more times.
7. Add legitimate urgency if real; use no false scarcity.
8. Explain how easy/supported getting started is.
9. Ask directly for the order or next commitment.

## Frame, don't front-load

Do not dump every benefit in the first presentation. Human certainty rises in steps. Give enough to build the first logical frame, then use loops to strengthen certainty after objections.

## Energy In / Benefits Out

Before buying, the buyer weighs total required energy against expected benefits.

**Energy in:** money, time, paperwork, hassle, risk, implementation burden, cognitive load.

**Benefits out:** solved problem, avoided pain, future gain, emotional relief, status, speed, confidence.

Rules:

- Never mention price or effort alone.
- Rebalance price/effort with benefits and ease.
- Reduce actual friction where possible.
- If a process is complex, promise support truthfully; do not pretend it is simple.

### Energy-balanced close pattern

```text
Getting started is [truthful simplicity/support statement].
What you get is [benefit 1], [benefit 2], and [benefit 3].
So the next step is [specific ask]. Sound fair enough?
```

## Buy signal response

If the buyer asks price, timeline, or next steps, treat it as energy equation moment.

Weak:

> It costs $3,000.

Stronger:

> It's a cash outlay of $3,000, and for that you get [benefit 1], [benefit 2], and [benefit 3]. Getting started is [ease/support]. Sound fair enough?
