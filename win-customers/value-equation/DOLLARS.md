# Dollars — money modes

Run only when the user asks what it is worth, what to charge, or to stack value. **Pick a mode before a second number.** State the mode in one line.

Value (buyer upside) and **price** (what they pay) are different. Do not conflate them unless the user asks for a ratio.

## Trigger routing

| Mode | Use when | Example phrases |
|------|----------|-----------------|
| **Audit** | One honest economic number for pricing prep | "what's it worth," "value to them," "defensible," "pricing" |
| **Stack** | Proposal / no-brainer / stacked value | "stack value," "line items," "10:1," "no-brainer," "offer card" |
| **Ratio** | User named a price | "$5k a month," "is X fair," "10% of value" |

If the user says **"answer directly," "just the number," "stop confusing"** while discussing money → **Audit**, lead with **one** number in the first sentence, then at most one short block.

## Unit

Require **per month**, **per year**, or **once**. If missing, ask once and stop until answered.

## Audit mode

1. **Lead with one headline number** — usually **time value**: hours saved per week × weeks per month × loaded hourly rate. Label each input *(guess)* in the same sentence.
2. **Optional second estimate** — **result value** (margin, hire avoided, spend protected). Keep separate; **do not add** to the headline unless the user asks for a combined total.
3. The user decides price. **Do not** recommend a fee.
4. **Done when** the user has one headline they accept.

## Stack mode

1. **Line items** — each row: **$/unit** + **why a skeptical buyer nods** (not why you like it).
2. **Stack total** — sum for **sales positioning** only.
3. **Guaranteed floor** — one line tied to the **locked guarantee** (e.g. hours reclaimed), if any.
4. **Defensibility rules**
   - No double-counting the same hours across rows.
   - Your deliverable (monitoring, guarantee) is not a separate value line — it's how the outcome is delivered.
   - Episodic wins (churn save) — copy bullet, not recurring $/mo, unless the user insists.
5. If the user asks **"defensible"** or **"would they agree"** → drop weak rows; keep **2–3** lines max.
6. **Ratio** (10:1, etc.) only if the user raised it; compare stack total to **their** price, not yours.

## Ratio mode

1. Require an accepted **Audit** headline or **Stack** total first (or confirm one in one line).
2. User's price must honor a **locked refund/guarantee** if one exists.
3. Say whether price sits **under** accepted value. **Do not** pick or change their price.

## After dollars

Stop. Do not reopen drivers unless the user asks. If target price implies **10:1** against a thin stack → say **widen scope** or **upmarket avatar** (see winning-markets handoff), do not inflate stack lines.
