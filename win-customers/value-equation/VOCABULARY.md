# Shared vocabulary (*$100M Offers*)

Use **book terms** in user-facing text. Tags: *(book)* official; *(workflow)* agent-only — never say these to the user unless explaining the process.

## Market selection *(winning-markets)*

| Book term | Meaning |
|-----------|---------|
| **Starving crowd** | Demand so strong the market forgives weak offer and persuasion |
| **Health / Wealth / Relationships** | The three primary markets |
| **Pain** | Massive pain — desperate need, not nice-to-have; *the pain is the pitch* |
| **Purchasing power** | They can pay the price you need |
| **Easy to target** | You can find them in lists, groups, titles, venues |
| **Growing** | Tailwind market (or time-boxed spike) |
| **Avatar** | Specific person the offer is for (sub-niched) |
| **Niche** | Committed slice of market; *don’t niche slap* |
| **Grand Slam Offer** | Offer strong enough to win in a normal market *(downstream — value equation)* |

**Three levers *(book)*:** starving crowd (market) → offer strength → persuasion skills.

*(workflow)* Validate / Discover, handoff, Winning Market Summary, pillar scores 1–10, starving crowd / normal / bad market labels.

## Value Equation *(value-equation)*

**Formula *(book)*:**  
`Value = (Dream Outcome × Perceived Likelihood of Achievement) / (Time Delay × Effort & Sacrifice)`

| Book term | Short label in ledger *(workflow)* |
|-----------|-----------------------------------|
| **Dream Outcome** | Dream |
| **Perceived Likelihood of Achievement** | Likelihood |
| **Time Delay** (perceived time between start and achievement) | Time Delay |
| **Effort & Sacrifice** | Effort & Sacrifice |

**Book phrases:** *Perception is reality.* *Get the bottom to zero.* *Channel desire* (don’t create it). **Dream Outcome** = the **vacation** (destination + experience), not the **plane flight** (membership, delivery, vehicle). **Vehicle** = way the outcome is delivered; compare two **vehicles** with the same dream outcome. **Psychological vs logical solutions.** **Fast wins.** **Fast beats free.**

*(workflow)* CREATE / EVALUATE, ledger, lock, ladder rung, value score (composite), feasibility check.

**Do not use with the user:** “the result / the belief / the wait / the work” as substitutes for the four drivers; “Exceptional band”; invented pillar nicknames (Money, Targeting only inside agent tables if mapped to Purchasing power / Easy to target).
