# Pipeline Laws and Activity Math

## Core concept

Pipeline health is a lagging result of prospecting behavior. Use three laws to diagnose need, timing, and replacement, then use personal ratios to convert an outcome target into controllable daily activity. (Blount, chs. 5-6, pp. 25-40.)

## The three laws

### Universal Law of Need

The more desperately a seller needs a deal, the more likely emotion, weak posture, and poor decisions will damage it. A broad, active pipeline reduces dependence on any one opportunity. (Ch. 5, p. 27.)

### 30-Day Rule

Prospecting performed now affects results in a later selling period. The book frames a common B2B pattern as current-month activity paying across the following quarter, while warning that shorter sales cycles compress the interval. Treat the exact lag as a hypothesis to verify against the user's cycle. (Ch. 5, pp. 28-29.)

### Law of Replacement

A closed deal implies that several other opportunities will not close, according to the seller's historical win rate. Replace the full statistical cohort consumed by a win or loss, not merely the one record that left the CRM. (Ch. 5, pp. 30-31.)

## Conversion chain

Build the math from the user's observed data:

```text
revenue target
÷ average deal value
= wins required

wins required
÷ opportunity-to-win rate
= qualified opportunities required

qualified opportunities required
÷ appointment-to-opportunity rate
= appointments required

appointments required
÷ conversation-to-appointment rate
= conversations required

conversations required
÷ touch-to-conversation rate
= touches required
```

Do not invent rates. If data is absent, request a baseline or label a short measurement sprint instead of presenting benchmark guesses as fact. This preserves the book's insistence on knowing one's own numbers. (Ch. 6, pp. 36-40.)

## Efficiency and effectiveness

- **Efficiency:** Activity produced inside the allotted block. (Ch. 6, pp. 38-39.)
- **Effectiveness:** Outcomes divided by the relevant activity. (Ch. 6, pp. 38-39.)
- **Performance:** The balance of efficiency and effectiveness, not either one alone. (Ch. 6, pp. 38-39.)

Track at minimum:

| Stage | Count | Ratio |
|---|---:|---:|
| Touches |  |  |
| Live conversations or replies |  | conversations ÷ touches |
| Appointments |  | appointments ÷ conversations |
| Qualified opportunities |  | opportunities ÷ appointments |
| Wins |  | wins ÷ opportunities |
| Pipeline removed |  | closed-lost + disqualified + won |
| Opportunities added |  | new qualified opportunities |

## Diagnostic rules

- If closing activity is high but new opportunities are low, expect a later gap under the 30-Day Rule. (Ch. 5, pp. 28-35.)
- If one deal must close for survival, diagnose the Universal Law of Need before coaching closing technique. (Ch. 5, p. 27.)
- If wins occur but the pipeline shrinks, apply replacement math using the historical win rate. (Ch. 5, pp. 30-31.)
- If activity feels high but counts are low, use visible manual tracking during the block. (Ch. 6, p. 40.)
- If activity is high and outcomes are weak, inspect list quality, message, channel, and objective before demanding more volume. (Ch. 6, pp. 36-40.)

## Copy patterns

- "Which earlier activity gap could explain today's pipeline?" (Ch. 5, pp. 28-35.)
- "How many opportunities must enter for every win?" (Ch. 5, pp. 30-31.)
- "What did the tracking sheet record—not what did the day feel like?" (Ch. 6, p. 40.)
- "Is the problem efficiency, effectiveness, or both?" (Ch. 6, pp. 38-39.)
- "What controllable activity will rebuild the next selling period?" (Ch. 5, pp. 34-35.)

## Pipeline review workflow

1. Export or list every open opportunity with age, stage, next step, and expected timing. (Ch. 5, pp. 25-35.)
2. Separate active, stale, disqualified, won, and lost records using evidence rather than hope. (Ch. 5, pp. 28-35.)
3. Count new qualified opportunities created by week or selling period. (Ch. 5, pp. 28-35.)
4. Compare inflow with the number of opportunities statistically consumed by wins and losses. (Ch. 5, pp. 30-31.)
5. Trace current weakness back through the relevant sales-cycle lag. (Ch. 5, pp. 28-35.)
6. Calculate the next period's activity from observed conversion ratios. (Ch. 6, pp. 36-40.)
7. Set a daily activity floor and a review cadence. (Chs. 5-6, pp. 25-40.)

## Completion criteria

- The diagnosis distinguishes a prospecting gap from a closing gap. (Ch. 5, pp. 28-35.)
- Every numeric input comes from the user or is marked unknown. (Ch. 6, pp. 36-40.)
- Replacement covers the statistical cohort, not only the won record. (Ch. 5, pp. 30-31.)
- The plan names both an activity target and the outcome ratio it should influence. (Ch. 6, pp. 38-40.)
- The next review is late enough to observe the sales-cycle lag but early enough to correct activity. (Ch. 5, pp. 28-35.)
